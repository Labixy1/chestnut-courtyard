# Manage Toolbox

1. Store the real tool name, category, verified official URL, purpose, key capabilities, use cases, and a concrete example.
2. Reuse existing categories where possible.
3. Avoid duplicate entries; update the existing item instead.
4. Mark genuinely new or recently changed entries with a temporary new state.
5. A supplied link may be an official page or a news article. Read it, identify the actual tool, and prefer its verified official address over the article address.
6. Verify links before claiming a tool was added successfully.
