# Archive Travel

1. Keep departure date, return date, place, summary, reflection, and two or three representative photos.
2. Group the travel page by destination or trip, never as an unstructured photo stream.
3. Let AI draft a factual reflection summary and a separate companion response, but preserve the owner's editable original words.
4. Store saved travel reflections in `travel_only` scope. Never inject them into the tree hollow, learning conversations, or ordinary butler replies.
5. Use 回家 for the travel return action.
6. Follow `companion-dialogue` when responding to a reflection. Use only the matching trip plus at most one explicit companion preference.
7. A preview summary does not create memory; only the explicit save action commits a travel memory event.
