# Manage Memory

1. Record immutable evidence first; a behavior observation is not a memory conclusion by itself.
2. Distill evidence into cards with a kind, category, statement, status, confidence, evidence ids, scope, and verification time.
3. Explicit "remember this" instructions activate a card immediately. Inferred cards remain candidates until repeated evidence reaches the configured threshold.
4. Candidate cards never affect execution. Build each task context from relevant active cards only, and let the owner's current instruction override every remembered default.
5. Start with stable base categories. Create an owner-requested category immediately; inferred categories remain suggestions until at least three related cards support them.
6. Deduplicate category names and aliases. Support card moves and category rename, merge, and delete so taxonomy does not fragment.
7. Treat 树洞, 密阁, and highest secrets as a separate sealed vault. Never copy sealed originals into ordinary cards or task context.
8. Read sealed content only when the owner explicitly asks and steward permission is enabled, using the smallest task-relevant scope.
9. Preserve evidence, time, confidence, corrections, and tombstones. Permanent forgetting must prevent old imports from resurrecting deleted memory.
10. AI distillation may merge duplicates, resolve supported conflicts, and rewrite the readable profile only through structured proposals validated against card ids, evidence thresholds, and sealed-data boundaries. Keep the deterministic profile generator as fallback and retain a before/after run record.
11. Separate memory by purpose: `learning_format` for learning and general communication, `companion_style` for explicit companionship preferences, `travel_only` for a matching trip, and `record_only` for archives that must not shape replies.
12. Never inject the complete profile into a reply. Select zero to two relevant items, exclude recently used ids, and expose selected ids for repetition control.
13. Derive a privacy-safe inner tendency only from repeated sealed evidence, and use it only in the tree hollow when the current message explicitly signals continuity.
