# 阿栗技术文档

这套文档同时服务两类读者：主人用它理解和操作小院，技术人员用它接手开发、部署、排错与测试。

![阿栗小院](https://github.com/user-attachments/assets/a7c5050f-d420-42f7-8c5a-c00890046864)

## 阅读路径

- 想快速了解产品：先读 [PRD](01-PRD.md)，再读 [使用指南](02-使用指南.md)。
- 想接手代码：先读 [系统架构](03-系统架构.md)，再读 [模块与功能规格](04-模块与功能规格.md)。
- 想确认数据是否安全同步：读 [数据同步与安全](05-数据同步与安全.md)。
- 想维护 AI：读 [AI 与接口调用链](06-AI与接口调用链.md)。
- 想发布或验收：按 [测试与运维手册](07-测试与运维手册.md) 执行。
- 想换 Codex 账号或学习对话式构建方法：读 [Codex 协作与迁移指南](08-Codex协作与迁移指南.md)，新 Codex 先从仓库根目录的 [接手入口](../CODEX_START.md) 开始。

## 仓库边界

GitHub 只保存代码、公开图片、空白初始数据、测试和文档。私人记忆、树洞内容、旅行、答案、密钥、上传图片与云端快照不进入 Git。
