# PRD：阿栗私人小院

## 1. 产品定义

阿栗是一个以“私人小院”为视觉入口的个人 AI 工作空间。它把资讯阅读、产品训练、持续学习、记忆整理、旅行记录和情绪表达放进相互独立但能共享上下文的房间中。

产品不是通用聊天壳。核心价值是让一次输入形成可追溯结果：资讯变成笔记与工具卡，答题变成多次作答档案，问答变成知识专题，经历变成可控记忆。

## 2. 用户与场景

| 用户 | 主要场景 | 成功标准 |
| --- | --- | --- |
| 主人 | 每天在手机和电脑继续同一份内容 | 结构化数据不因换设备丢失或整表覆盖 |
| 主人 | 阅读 AI 资讯并留下判断 | 可记录笔记、稍后看、归档或加入工具箱 |
| 主人 | 训练 AI 产品判断力 | 题目、答案、评分、标准答案、重做记录完整保留 |
| 主人 | 围绕真实问题持续学习 | 多轮对话可追溯，并归纳为易复习的专题 |
| 面试访客 | 快速理解产品能力 | 示例完整、私人数据隔离、AI 由主人临时开启 |

## 3. 产品原则

1. 云端保存结构化主数据，本地保留可离线读取的缓存。
2. 私密内容默认不进入公开构建、GitHub 或演示环境。
3. AI 只能把成功的工具结果说成已完成；失败必须明确显示。
4. 不用一个聊天页面承载所有内容，聊天、专题、档案分开呈现。
5. 手机重排只作用于移动断点，桌面空间布局保持独立。
6. 自动更新无新内容时不制造新版本，全部来源失败时必须报错。

## 4. 功能范围

### 首页与导航

- 根据杭州实时天气切换晴、阴、雨、雷雨、雾、雪和晨间背景。
- 桌面通过场景热点进入公告、黑板、树洞、果园、旅行、卧室和工具箱。
- 手机使用固定五栏导航和“更多”功能面板。
- PWA 名称为“阿栗”，使用狗头图标，可保存到主屏幕。

### 内容与学习

- 公告板：固定每周一、周三、周五 08:00 更新，去重、历史版本、阅读笔记、工具导入。
- 黑板：每日题目、换题、星标、AI 批改、重新核分、完整历史与多次作答。
- 成长田：多轮解惑、历史会话、知识专题、五块地、生长、浇水、收成与背包。
- 工具箱：按使用场景整理工具；公开 Skills 与系统 Skills 分开。

### 私人记录

- 树洞：倾诉、签语、对话与草堆影像，记录可编辑和删除。
- 旅行：地点、日期、照片、感悟摘要；保存后清空输入。
- 密阁：可读记忆档案、分类、证据、遗忘、系统 Skills 和 30 项可调用能力。
- 卧室：日夜场景切换，不承载重复的密阁过渡页。

## 5. 非功能要求

| 维度 | 要求 |
| --- | --- |
| 隐私 | 私人构建必须登录；演示与私人 KV 隔离；仓库隐私扫描通过 |
| 可靠性 | 主模型失败自动切备用模型；任务运行、成功、失败可追踪 |
| 同步 | 唯一记录合并、同记录按更新时间决胜、删除不复活 |
| 性能 | 首屏背景压缩为 WebP，大图按需缓存，移动端使用独立尺寸 |
| 可访问性 | 主要按钮具备文字或 `aria-label`；密码可显示/隐藏 |
| 可维护性 | 无前端构建依赖；Python 本地服务与 Worker 保持 API 对齐 |

## 6. 验收标准

- 393 x 852 和 1280 x 720 下无页面级横向溢出或关键控件遮挡。
- 两台设备分别新增记录后云端得到并集；冲突保留较新记录；删除后旧设备不能复活。
- 完全空白或“不会”类答案可得 0 分；包含观点的答案不能无依据全 0。
- 公告没有新内容时版本数不增加；全部资讯源失败时显示失败原因。
- 公开构建不含记忆、树洞、旅行、上传图、口令和 API Key。
- 自动化测试、浏览器回归和生产健康检查全部通过后才发布。
